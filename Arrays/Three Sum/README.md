# 3Sum (LeetCode 15)

## Approaches

### 1. Brute Force
- Time: O(n³)
- Space: O(1)

### 2. Better
- Time: O(n² log n)
- Space: O(n)

### 3. Optimal (Two Pointers)
- Time: O(n²)
- Space: O(1) (excluding output)

## Key Learning
- Sorting enables the two-pointer technique.
- Skip duplicate values to avoid repeated triplets.
- Two pointers reduce one loop from O(n) to O(1) movement.
